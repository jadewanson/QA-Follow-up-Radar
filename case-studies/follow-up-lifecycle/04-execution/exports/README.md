# Execution Evidence Exports

This directory contains portable snapshots of the execution and defect records used in the Follow-Up Item Lifecycle case study.

- [Zephyr execution results](zephyr-execution-results.md) — cycle summaries and test-level results for FUT-R1, FUT-R2 and FUT-R3.
- [Zephyr execution results CSV](zephyr-execution-results.csv) — machine-readable copy of the execution matrix.
- [Jira FUT-13 defect export](jira-fut-13-defect.md) — defect report, reproduction evidence, traceability and retest outcome.

The live Jira and Zephyr records remain the operational source of truth. These exports make the completed QA evidence reviewable from the portfolio repository.
